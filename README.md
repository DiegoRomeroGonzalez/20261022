# Project Title

Cálculo de áreas a partir de dimensiones.


## Authors

Diego Romero

## Installation

El programa le pedirá que elija una figura, las figuras válidas son el cuadrado y el círculo. Usted, debe escribir la figura cuyo área desee saber. En el caso de que usted elija "cuadrado", el programa le pedrira que introduzca la dimensión del lado del mismo. Acto seguido, el programa le devolverá el área del cuadrado. Lo mismo ocurre con el dículo, solo que en vez de introducir la medida del lado, se le pedirá que introduzca la medida del radio del mismo. Tenga en cuenta, que tanto en en el cuadrado como en el círculo, las unidades en las que estarán expresadas las unidades de su figura serán las mismas que aquellas en las que usted introdujo la medida.
